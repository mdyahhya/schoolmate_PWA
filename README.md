# OpenSoftwares Admin PWA

> Master Multi-School Management & Educational Video Curator  
> Powered by [OpenSoftwares Pvt. Ltd.](https://opensoftwares.in)

## Features
- **Master Multi-School Management:** Enroll schools, set unique `school_code`, and set `erp_passcode` (admin password required by Desktop/Web ERP).
- **Staff & Teacher Accounts:** Provision teacher logins with plain-text passwords and assigned class/section.
- **Student Roster & Parent Logins:** Enroll students with Class, Section, and Roll Numbers.
- **Educational Feed Curator:** Paste any YouTube video link with automatic video ID extraction, thumbnail validation, category tagging, and instant cloud publishing.
- **PWA Installation:** Installable on Android, iOS, and Desktop with offline caching.

## Vercel Deployment
To host on Vercel:
1. Connect this repository (`schoolmate_PWA`).
2. Add Environment Variable:
   - **Name:** `PASS`
   - **Value:** `#flutter` (or your custom password)
3. Deploy!
